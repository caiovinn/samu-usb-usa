Movendo 10 das 123 unidades (48 km ao todo), o Gini cai de 0,224 para 0,057 — 75% do ganho de equidade possível. Planejar pela regra clássica (p-median) custa apenas −0,2% de tempo esperado a mais que o ótimo sob Huff — o ganho real do modelo está na equidade (2,8× melhor que o p-median), não na eficiência.

Seção 5Como reproduzir

Ambiente: ver SETUP.md (uv sync, mais npm install se for regenerar os decks). Com fase2_sao_paulo/_raw/ já presente (não incluso no repositório — ver fase2_sao_paulo/coleta/pull_dados.py):

uv run python -m fase2_sao_paulo.experimentos.monta
uv run python -m fase2_sao_paulo.testes.teste_monta

Seção 6Limitações e próximos passos

Tratadas em detalhe em CONTEXTO_PROJETO.md §6-7 e em matematica_usb_usa.html §3.6-3.8 e §8-9. Resumo do que esta execução muda nessa lista:

  • β arbitrado, não estimado — agora testado em faixa (§4 acima), não apenas assumido. A calibração contra dado real de despacho continua em aberto.
  • Demanda = população residente — inalterado; ponte prevista para um modelo bayesiano CAR/ICAR (matematica_usb_usa.html §8).
  • Sem fila nem ocupação real — inalterado (matematica_usb_usa.html §9).
  • Um município, não a rede estadual — inalterado.
